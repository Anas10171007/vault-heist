# P2 B10–B12 (Arslan)

Branch: `arslan/B4-B9-finish`.

## B10 Replay scrubber

- `AnimationController::seekTo(index)` rebuilds visuals for a log prefix.
- `ReplayScrubber` draws a track and maps click/drag X → index.
- Act 4 keeps a **level timeline**: each accepted move appends to `levelTimeline`;
  the scrubber can rewind through the whole run from the level baseline (not only
  the last swap). Undo clears the timeline and restarts it from the restored state.
- Rule: scrubber never changes the live model.

## B11 Save + leaderboard

- `SaveManager` writes/reads `data/save/progress.txt` (`VHSAVE1`, level id + best stars).
- `Leaderboard` writes/reads `data/save/leaderboard.txt` (`VHLEAD1`, top 10, own sort).
- Boot: `SaveManager::loadProgress(session)`.
- Mission end: `saveProgress` + `addScore(selectedLevel, score)`.
- `LeaderboardScreen` reloads on show.

## B12 Sandbox

- Structure cycle: Binary, BST, AVL, Max Heap.
- Ops: insert / delete|extract / random / clear / buildMaxHeap (heap only).
- Trees redraw via `TreeLayout`; heap uses `HeapView` + animation + scrubber.
- No campaign scoring; calls existing model APIs only.
